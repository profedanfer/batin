Sistema Biblioteca

Practica DDL y DML con una base de datos real que corre directamente en el navegador. No necesitas instalar nada — sql.js ejecuta SQLite aquí mismo.

Iniciando base de datos…

Script de creación y carga inicial

Este es el script completo que inicializa la base de datos. Se ejecuta automáticamente al cargar la página.

Creación de tablas (DDL)
Estados
CREATE TABLE Estados (
    idEstado INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL UNIQUE,
    descripcion VARCHAR(30) NOT NULL UNIQUE
);
Generos
CREATE TABLE Generos (
    idGenero INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL UNIQUE,
    descripcion VARCHAR(30) NOT NULL UNIQUE
);
Autores
CREATE TABLE Autores (
    idAutor INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL UNIQUE,
    nombre VARCHAR(30) NOT NULL,
    apellido VARCHAR(30) NOT NULL,
    idEstado INTEGER NOT NULL,
    FOREIGN KEY (idEstado) REFERENCES Estados(idEstado)
);
Libros
CREATE TABLE Libros (
    idLibro INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL UNIQUE,
    titulo VARCHAR(30) NOT NULL,
    codigo VARCHAR(20),
    anioPublicacion INTEGER,
    idGenero INTEGER NOT NULL,
    FOREIGN KEY (idGenero) REFERENCES Generos(idGenero)
);
RelLibrosAutores
CREATE TABLE RelLibrosAutores (
    idLibro INTEGER NOT NULL,
    idAutor INTEGER NOT NULL,
    PRIMARY KEY (idLibro, idAutor),
    FOREIGN KEY (idLibro) REFERENCES Libros(idLibro),
    FOREIGN KEY (idAutor) REFERENCES Autores(idAutor)
);

Estructura de la base de datos

Estados
PKNN idEstado INTEGER
NNUQ descripcion VARCHAR(30)
Generos
PKNN idGenero INTEGER
NNUQ descripcion VARCHAR(30)
Autores
PKNN idAutor INTEGER
NN nombre VARCHAR(30)
NN apellido VARCHAR(30)
FKNN idEstado INTEGER
Libros
PKNN idLibro INTEGER
NN titulo VARCHAR(30)
codigo VARCHAR(20)
anioPublicacion INTEGER
FKNN idGenero INTEGER
RelLibrosAutores
PKFKNN idLibro INTEGER
PKFKNN idAutor INTEGER
Relaciones: Autores.idEstado → Estados.idEstado  |  Libros.idGenero → Generos.idGenero  |  RelLibrosAutores.idLibro → Libros.idLibro  |  RelLibrosAutores.idAutor → Autores.idAutor
Recordá: En SQLite, ALTER TABLE no permite cambiar tipos de datos ni agregar restricciones UNIQUE directamente. Cuando se necesita ese cambio, hay que recrear la tabla correctamente.

Ejercicio 9 – JOIN completo
Se unen las cuatro tablas. El operador || concatena nombre y apellido del autor.
SELECT 
    L.titulo,
    G.descripcion AS genero,
    A.nombre || ' ' || A.apellido AS autor
FROM Libros L
JOIN Generos G ON L.idGenero = G.idGenero
JOIN RelLibrosAutores R ON L.idLibro = R.idLibro
JOIN Autores A ON R.idAutor = A.idAutor;
Ejercicio 10 – Corrección de estructura (DDL)
Sin UNIQUE en descripcion, la tabla permitiría insertar "Informática" dos veces, generando duplicados y ambigüedad en las consultas. Para corregirlo sin recrear la tabla se usa CREATE UNIQUE INDEX. Para cambiar el tipo de dato de una columna en SQLite, hay que recrear la tabla con el tipo correcto. 
-- Verificar si hay duplicados antes de crear el índice
SELECT descripcion, COUNT(*) FROM Generos GROUP BY descripcion HAVING COUNT(*) > 1;
SELECT descripcion, COUNT(*) FROM Estados GROUP BY descripcion HAVING COUNT(*) > 1;

-- Agregar UNIQUE a descripcion (si no hay duplicados)
CREATE UNIQUE INDEX uqGenerosDescripcion ON Generos(descripcion);
CREATE UNIQUE INDEX uqEstadosDescripcion ON Estados(descripcion);

-- Corregir anioPublicacion de DATE a INTEGER (recrear tabla)
ALTER TABLE Libros RENAME TO Libros_old;

CREATE TABLE Libros (
    idLibro INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL UNIQUE,
    titulo VARCHAR(30) NOT NULL,
    codigo VARCHAR(20),
    anioPublicacion INTEGER,
    idGenero INTEGER NOT NULL,
    FOREIGN KEY (idGenero) REFERENCES Generos(idGenero)
);

INSERT INTO Libros (idLibro, titulo, codigo, anioPublicacion, idGenero)
SELECT idLibro, titulo, codigo, CAST(anioPublicacion AS INTEGER), idGenero
FROM Libros_old;

DROP TABLE Libros_old;
