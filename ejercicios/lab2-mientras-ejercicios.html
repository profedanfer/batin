👩‍💻 Techi
El ciclo for sabía de antemano cuántas veces iba a repetir.
El ciclo while... no. El while no cuenta. Evalúa.
Repite mientras algo sea verdadero. Y cuando eso deje de serlo, para.
# O no para nunca. Eso también puede pasar.
🤖 Bit
Anatomía del ciclo Mientras:

while <condicion>:
    # bloque que se repite
    # ALGO debe cambiar aquí

Tres preguntas antes de escribirlo:
1. ¿Cuál es la condición de continuación?
2. ¿Qué cambia dentro del ciclo para que alguna vez sea falsa?
3. ¿Qué necesito inicializar antes de entrar?
🦊 Gatiel
Pregunta trampa: ¿qué pasa acá?

x = 5
while x > 0:
    print(x)

# <-- x nunca cambia. El ciclo... ¿para?

No. Nunca para. Eso se llama bucle infinito.
En clase vas a tener que matar el proceso con Ctrl+C.
En sistemas reales, eso se llama incidente de producción.
# Pequeña diferencia.
👩‍💻 Techi
Entonces, ¿cuándo uso while en vez de for?

Cuando no sabés de antemano cuántas veces vas a repetir.

Ejemplos reales:
→ Pedir la contraseña hasta que sea correcta.
→ Leer datos hasta que el usuario escriba "fin".
→ Intentar conectar a un servidor hasta que responda.
→ Esperar que un archivo termine de descargarse.

El while es el ciclo de los procesos reales.
