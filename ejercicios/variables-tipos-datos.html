// 01

¿Qué es una variable?

Una variable es un espacio con nombre donde un algoritmo guarda un dato mientras se ejecuta. El valor adentro puede cambiar — por eso se llama "variable" — pero el tipo de dato que acepta esa caja queda fijo desde que se declara.

Una constante, en cambio, es una caja que se sella después de guardar el valor una única vez: no se puede volver a abrir para cambiarlo.

Entero

Números sin parte decimal, positivos, negativos o cero. Se usan para contar cosas: cantidad de alumnos, número de intentos, un índice.

17 -4 0 1000

Real

Números con parte decimal. Se usan cuando el valor necesita precisión: un promedio, un precio, una altura.

3.14 -0.5 100.0 7.25

Carácter

Un único símbolo: una letra, un dígito o un carácter especial. Va entre comillas simples.

'A' '7' '@' 'ñ'

Cadena (String)

Una secuencia de caracteres — texto. Va entre comillas dobles. Internamente se construye a partir del tipo Carácter.

"Daniela" "BATIN 2026" ""

Booleano

Solo tiene dos valores posibles: Verdadero o Falso. Es el resultado natural de una comparación (==, >, <, etc.) o de una expresión lógica (AND, OR, NOT).

Nombres válidos para variables

Escribí un nombre de variable y comprobá si es válido según las reglas estándar de algorítmica.

Escribí algo arriba para validar ↑
• Debe empezar con una letra (no con número ni símbolo)
• Solo puede contener letras, números y guion bajo (_) — sin espacios ni tildes
• No puede ser una palabra reservada del lenguaje (si, entonces, mientras, para, etc.)
• Es sensible a mayúsculas: nota y Nota son variables distintas
// 04

Constantes, ámbito y conversión de tipos

Una constante se declara una sola vez y su valor no puede cambiar durante toda la ejecución del algoritmo. Se usan para valores que no deberían modificarse por error: un IVA, un límite máximo, un valor de PI.

// Variable: el valor puede cambiar Definir edad Como Entero edad ← 17 edad ← 18 // válido // Constante: el valor queda fijo Definir IVA Como Constante Real IVA ← 0.10 IVA ← 0.15 // ERROR: no se puede reasignar

💡 Usar constantes para valores fijos evita errores silenciosos: si alguien intenta cambiar el IVA por accidente en medio del código, el algoritmo directamente no compila.

El ámbito (o alcance) de una variable define en qué parte del algoritmo esa variable existe y puede usarse.

Definir total Como Entero // ámbito GLOBAL total ← 0 SubProceso sumarNota(nota) Definir bonus Como Real // ámbito LOCAL bonus ← 0.5 total ← total + nota + bonus FinSubProceso // "bonus" NO existe fuera del SubProceso. // "total" sí, porque es global.

Global: declarada fuera de cualquier función/subproceso — visible en todo el algoritmo.   Local: declarada dentro de una función/subproceso — solo existe mientras esa parte se ejecuta.

A veces un dato de un tipo necesita usarse como si fuera de otro tipo. Probá el conversor:

Conversión implícita: el lenguaje la hace solo (ej: sumar un Entero con un Real da un Real automáticamente). Conversión explícita: la pedís vos a propósito, por ejemplo para mostrar un número dentro de un mensaje de texto (convertir un Entero a Cadena).
