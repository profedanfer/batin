Instalación paso a paso: descargar, instalar y verificar el JDK

Antes de escribir una sola línea de código hace falta el JDK (Java Development Kit): el paquete que trae el compilador, la máquina virtual y todas las herramientas para desarrollar en Java. En las notebooks del aula ya está instalado (OpenJDK, parte del setup portátil), pero conviene que sepan hacerlo de cero para su casa o para cualquier PC nueva.

Descargar el JDK. Se descarga de forma gratuita. Dos opciones confiables:
  • Eclipse Temurin (Adoptium) — adoptium.net — distribución de OpenJDK, gratuita y sin necesidad de crear cuenta. La recomendada para empezar.
  • Oracle JDK — oracle.com/java — la versión oficial de Oracle, también gratuita para uso general.
Eligen la versión LTS (Long Term Support — de soporte prolongado, más estable) más reciente, por ejemplo Java 21, y el instalador correspondiente a su sistema operativo (Windows x64, en la mayoría de los casos).
Instalar (Windows). Ejecutan el instalador descargado (.msi) y siguen el asistente con las opciones por defecto. Un detalle importante: si el instalador ofrece una casilla como "Set JAVA_HOME variable" o "Add to PATH", hay que dejarla tildada — eso evita tener que configurar las variables de entorno a mano después.
Verificar la instalación. Abren una terminal (Símbolo del sistema o PowerShell en Windows) y escriben: 
java -version
javac -version
Si todo salió bien, ambos comandos muestran el número de versión instalada. Si en cambio aparece algo como "'java' no se reconoce como un comando...", el problema es de configuración del PATH — ver el recuadro de errores comunes más abajo.
Elegir un editor de código. Con el JDK alcanza para compilar y ejecutar desde la terminal, pero escribir código en el Bloc de notas es incómodo. Se recomienda Visual Studio Code (gratuito) con el paquete de extensiones "Extension Pack for Java", que agrega resaltado de sintaxis, autocompletado y un botón para ejecutar sin escribir los comandos a mano. No es obligatorio: la terminal + cualquier editor de texto también funciona, y es justamente lo que vamos a usar hoy en el aula (setup portátil, sin instalar nada nuevo).
Tres piezas que conviene distinguir desde el principio:
SiglaNombreQué es
JDKJava Development KitEl paquete completo para desarrollar: incluye el compilador (javac), herramientas y el JRE.
JREJava Runtime EnvironmentLo mínimo para ejecutar programas Java ya compilados (no incluye el compilador). Va incluido dentro del JDK.
JVMJava Virtual MachineLa máquina virtual que efectivamente corre el bytecode. Es la pieza que le da a Java el "escribí una vez, ejecutá en cualquier lado".
En el aula, con instalar el JDK ya tienen las tres cosas.
¿Qué es Java y cómo se ejecuta un programa? (teoría)

Java es un lenguaje de programación orientado a objetos. A diferencia de lenguajes como Python, un programa en Java pasa por dos etapas separadas antes de correr:

Compilación: el compilador (javac) traduce el código fuente (.java, texto que escribe la persona) a bytecode (.class), un código intermedio que no es código máquina todavía, sino un formato que entiende específicamente la JVM.
Ejecución: el comando java invoca a la JVM, que lee ese bytecode y lo va traduciendo a instrucciones que el procesador de esa PC específica puede correr.

La ventaja de este esquema en dos pasos: el mismo archivo .class corre igual en Windows, Linux o Mac, siempre que haya una JVM instalada — no hace falta recompilar el código para cada sistema operativo, como sí pasa en C o C++.

Primer programa: HolaMundo.java 
public class HolaMundo {
    public static void main(String[] args) {
        System.out.println("Hola, PataFeliz!");
    }
}

Explicación palabra por palabra:

PalabraQué significa
public class HolaMundoDefine una clase pública llamada HolaMundo. El nombre del archivo debe coincidir exactamente con el nombre de la clase: HolaMundo.java.
public static void mainEs el método por donde arranca la ejecución. public: la JVM puede llamarlo desde afuera. static: no hace falta crear un objeto para ejecutarlo. void: no devuelve ningún valor.
(String[] args)Parámetro que recibe argumentos escritos por consola (un arreglo de textos). Por ahora no lo vamos a usar, pero siempre va ahí.
System.out.println(...)System.out es el flujo de salida estándar (la consola). println imprime el texto y salta de línea.
;Cada instrucción en Java termina con punto y coma. Es obligatorio.
{ }Delimitan bloques de código: dónde empieza y dónde termina una clase, un método, etc.
Para compilar y ejecutar en la notebook (sin internet): 
javac HolaMundo.java
java HolaMundo
Esto genera HolaMundo.class y luego lo ejecuta. Java distingue mayúsculas de minúsculas, ¡ojo con eso!

Variables y tipos de datos

Una variable es un espacio en memoria con un nombre, un tipo y un valor. En Java, a diferencia de SQLite, siempre hay que declarar el tipo.

Ejemplo simple 
public class Variables {
    public static void main(String[] args) {
        int edad = 15;
        double promedio = 8.75;
        String nombre = "Ana";
        boolean aprobado = true;
        char inicial = 'A';

        System.out.println(nombre + " tiene " + edad + " años");
    }
}
TipoGuardaEjemplo
intNúmeros enteros15, -3, 2026
doubleNúmeros con decimales8.75, 3.14
StringTexto (nótese la S mayúscula: es una clase, no un tipo primitivo)"Ana"
booleanVerdadero o falsotrue / false
charUn solo carácter, entre comillas simples'A'
Un poco más complejo — operaciones y decisión:
int costoConsulta = 150000;
int descuento = 20000;
int total = costoConsulta - descuento;

if (total > 100000) {
    System.out.println("Consulta de alto costo: " + total);
} else {
    System.out.println("Consulta estándar: " + total);
}

Este ejemplo ya conecta con algo que conocen: costoConsulta es el mismo dato que van a ver en la tabla Consultas de PataFeliz. La idea es que vayan viendo que las variables de Java van a "espejar" las columnas de las tablas.

Clases y objetos

Una clase es un molde: define qué atributos (datos) y qué métodos (comportamientos) va a tener algo. Un objeto es una instancia concreta de esa clase, creada con la palabra new.

Ejemplo simple: clase Mascota 
public class Mascota {
    // Atributos: los datos que va a tener cada mascota
    String nombre;
    String especie;

    // Constructor: se ejecuta al crear el objeto con "new"
    public Mascota(String nombre, String especie) {
        this.nombre = nombre;
        this.especie = especie;
    }
}
PalabraQué significa
String nombre;Atributo (o "campo"): un dato que cada objeto Mascota va a tener propio.
public Mascota(...)Constructor: un método especial, con el mismo nombre que la clase, sin tipo de retorno. Se ejecuta automáticamente al crear el objeto.
this.nombrethis significa "este objeto que se está creando ahora". Se usa para diferenciar el atributo de la clase del parámetro recibido, que se llaman igual.
Creando y usando objetos (desde el main de otra clase):
public class PruebaMascota {
    public static void main(String[] args) {
        Mascota m1 = new Mascota("Toby", "Perro");
        Mascota m2 = new Mascota("Michi", "Gato");

        System.out.println(m1.nombre + " es un " + m1.especie);
        System.out.println(m2.nombre + " es un " + m2.especie);
    }
}

m1 y m2 son dos objetos distintos, cada uno con sus propios valores, creados a partir del mismo molde (la clase Mascota).

Ahora sí, la clase que vamos a usar con la base de datos. Fíjense que sus atributos son exactamente las columnas de la tabla Mascotas de PataFeliz:

Métodos

Un método es un bloque de código con nombre que realiza una tarea. Puede recibir parámetros y puede devolver un resultado.

Ejemplo simple: método sin retorno 
public void mostrarInfo() {
    System.out.println(nombre + " - " + especie);
}
Un poco más complejo: método con retorno 
public String describir() {
    return nombre + " (" + especie + ", " + raza + ")";
}

Este método devuelve un String en lugar de imprimirlo directamente. Quien lo llame decide qué hacer con el resultado: imprimirlo, guardarlo en otra variable, etc.

ParteQué significa
voidEl método no devuelve ningún valor.
String (antes del nombre)El método sí devuelve un valor, y ese valor es de tipo String.
returnCorta la ejecución del método y entrega el valor indicado a quien lo llamó.
Clase Mascota completa con su método:
public class Mascota {
    int idMascota;
    String nombre;
    String especie;
    String raza;
    String fechaNacimiento;
    int idPropietario;

    public Mascota(int idMascota, String nombre, String especie,
                   String raza, String fechaNacimiento, int idPropietario) {
        this.idMascota = idMascota;
        this.nombre = nombre;
        this.especie = especie;
        this.raza = raza;
        this.fechaNacimiento = fechaNacimiento;
        this.idPropietario = idPropietario;
    }

    public String describir() {
        return "#" + idMascota + " " + nombre + " (" + especie + ", " + raza + ")";
    }
}

Con esto ya tenemos todo lo que necesitamos para representar una mascota en memoria. Ahora falta un paso: en vez de escribir los datos a mano con new, vamos a traerlos desde la base de datos real. Para eso necesitamos JDBC.

Conexión a la base de datos con JDBC

JDBC (Java Database Connectivity) es la API que le permite a un programa Java hablar con una base de datos. Para SQLite necesitamos un driver: una librería externa que traduce las llamadas de JDBC al formato de archivo .db de SQLite.

Preparación (hacer antes de la clase, sin internet en el aula):
Descargar el driver sqlite-jdbc-3.xx.x.jar (una sola vez, con internet) desde Maven Central.
Copiar el .jar y el archivo PataFeliz.db a la carpeta del proyecto en cada notebook.
Compilar y ejecutar indicando el classpath (dónde están las librerías).
-- Windows --
javac -cp .;sqlite-jdbc-3.45.0.0.jar ConexionPataFeliz.java
java  -cp .;sqlite-jdbc-3.45.0.0.jar ConexionPataFeliz

-- Linux/Mac --
javac -cp .:sqlite-jdbc-3.45.0.0.jar ConexionPataFeliz.java
java  -cp .:sqlite-jdbc-3.45.0.0.jar ConexionPataFeliz
Programa mínimo: probar la conexión 
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;

public class ConexionPataFeliz {
    public static void main(String[] args) {
        String url = "jdbc:sqlite:PataFeliz.db";

        try (Connection conexion = DriverManager.getConnection(url)) {
            if (conexion != null) {
                System.out.println("Conexión exitosa a PataFeliz.db");
            }
        } catch (SQLException e) {
            System.out.println("Error de conexión: " + e.getMessage());
        }
    }
}
ParteQué significa
import java.sql...Trae las clases necesarias para trabajar con bases de datos: Connection, DriverManager, SQLException.
jdbc:sqlite:PataFeliz.dbLa URL de conexión. jdbc:sqlite: le dice al driver qué motor usar; lo que sigue es la ruta al archivo .db.
try (Connection conexion = ...)try-with-resources: abre la conexión y la cierra automáticamente al terminar el bloque, aunque ocurra un error. Evita conexiones "colgadas".
DriverManager.getConnection(url)Pide al driver que abra la conexión con esa URL y la devuelve como un objeto Connection.
catch (SQLException e)Si algo sale mal (archivo no existe, permisos, etc.), se captura el error en vez de que el programa se rompa de golpe.
Cargar registros: de la tabla Mascotas a objetos Java

Ahora unimos todo: la clase Mascota (tab 3-4) más la conexión JDBC (tab 5), para leer los registros reales de la tabla Mascotas y convertir cada fila en un objeto.

Programa completo 
import java.sql.*;
import java.util.ArrayList;

public class CargarMascotas {
    public static void main(String[] args) {
        String url = "jdbc:sqlite:PataFeliz.db";
        ArrayList<Mascota> mascotas = new ArrayList<>();

        String sql = "SELECT id_mascota, nombre, especie, raza, " +
                     "fecha_nacimiento, id_propietario FROM Mascotas";

        try (Connection conexion = DriverManager.getConnection(url);
             Statement stmt = conexion.createStatement();
             ResultSet rs = stmt.executeQuery(sql)) {

            while (rs.next()) {
                int id = rs.getInt("id_mascota");
                String nombre = rs.getString("nombre");
                String especie = rs.getString("especie");
                String raza = rs.getString("raza");
                String fecha = rs.getString("fecha_nacimiento");
                int idProp = rs.getInt("id_propietario");

                Mascota m = new Mascota(id, nombre, especie, raza, fecha, idProp);
                mascotas.add(m);
            }

        } catch (SQLException e) {
            System.out.println("Error al leer la base: " + e.getMessage());
        }

        // Ahora mascotas contiene objetos Java, no filas de tabla
        for (Mascota m : mascotas) {
            System.out.println(m.describir());
        }
    }
}
ParteQué significa
ArrayList<Mascota>Una lista dinámica que va a guardar objetos Mascota (a diferencia de un arreglo, puede crecer).
Statement / executeQueryStatement ejecuta sentencias SQL. executeQuery se usa específicamente para SELECT y devuelve un ResultSet.
ResultSet rsEs el "cursor" que apunta fila por fila al resultado del SELECT, muy parecido a recorrer los resultados en DB Browser.
rs.next()Avanza a la siguiente fila. Devuelve false cuando ya no hay más filas — por eso funciona como condición del while.
rs.getInt("id_mascota")Lee el valor de esa columna en la fila actual, con el tipo indicado (getInt, getString, etc.). El nombre debe coincidir con la columna real de la tabla.
for (Mascota m : mascotas)for-each: recorre cada objeto de la lista sin necesidad de un índice numérico.
Conexión con lo que ya saben de SQL: el SELECT de la línea sql es exactamente el mismo tipo de consulta que ya escribieron en DB Browser o en el laboratorio interactivo. JDBC no reemplaza el SQL: lo ejecuta desde Java y convierte cada fila del resultado en un objeto.
