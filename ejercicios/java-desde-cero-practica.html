Java desde cero — Práctica interactiva

Laboratorio · Gabinete de Informática — 3º BATIN

Esta página tiene un pequeño intérprete de Java integrado: podés escribir código real, apretar Ejecutar y ver la salida en la consola de abajo, sin instalar nada.
  • Soporta exactamente lo que vimos en clase: variables (int, double, boolean, char, String), Scanner, operadores y System.out.println.
  • No es una JVM completa — no reconoce condicionales, ciclos ni clases propias todavía. Para eso vamos a usar VS Code en el laboratorio.
  • Si un ejercicio usa Scanner, completá los valores simulados en el recuadro naranja antes de ejecutar.
  • Podés tocar "Ver solución" en cualquier momento para comparar tu código.
