HTML: primeros pasos

Etiquetas, encabezados, énfasis y enlaces: el alfabeto de toda página web. Techi piensa distinto. Bit ordena la lógica. Gatiel encuentra el camino.

📖 5 bloques ⏱ ~8 minutos de lectura 🎯 1er curso
// En esta guía
1. ¿Qué es una etiqueta? 2. Apertura y cierre 3. El esqueleto de un HTML 4. Encabezados y énfasis 5. Enlaces y errores comunes
01

¿Qué es una etiqueta HTML?

Una etiqueta (tag) le dice al navegador qué es cada parte del contenido: un título, un párrafo, una imagen, un enlace. HTML no decide cómo se ve nada — solo dice qué es cada cosa.

<p>Este es un párrafo.</p>
TECHI DICE
"Pensá en las etiquetas como carteles que colocás sobre cada objeto de una habitación: uno dice 'puerta', otro dice 'ventana'. El navegador lee los carteles, no adivina."
// Cada etiqueta tiene una forma
etiqueta de apertura → texto o contenido → etiqueta de cierre
02

Etiquetas con apertura y cierre

La mayoría de las etiquetas trabajan en pareja: una abre el contenido y otra lo cierra. La de cierre lleva una barra ( / ).

<p> ... </p>Párrafo de texto
<h1> ... </h1>Encabezado principal
<strong> ... </strong>Texto en negrita
<em> ... </em>Texto en cursiva
<a> ... </a>Enlace a otra página
<body> ... </body>Cuerpo del documento

No todas las etiquetas encierran contenido. Algunas representan un elemento único que no necesita nada adentro: se escriben solas.

<br> → salto de línea
<hr> → línea divisoria
<img src="logo.png"> → imagen
BIT DICE
"Son etiquetas vacías: no tienen texto adentro, así que no hay nada que cerrar. Si buscás su etiqueta de cierre, no la vas a encontrar — y está bien."
03

La estructura básica de un HTML

Todo documento HTML nace con la misma base: un esqueleto de tres etiquetas que envuelve absolutamente todo.

<html>
  <head>
    <title>Nombre de la página</title>
  </head>
  <body>
    <!-- Todo lo visible va aquí -->
  </body>
</html>
<html>Envuelve todo el documento
<head>Información que no se ve (título de la pestaña, configuración)
<body>Todo el contenido visible: textos, imágenes, enlaces
04

Encabezados y énfasis

Los encabezados marcan la importancia del texto. h1 es el título principal; h6, el más pequeño. No se eligen por tamaño, se eligen por jerarquía.

<h1>Título del proyecto
<h2>Sección principal
<h3>Subsección
<h4> <h5> <h6>Detalle, nota y texto de referencia
GATIEL DICE
"No uses h1 solo porque querés letra grande. Un buen documento tiene un único h1, y el resto de los encabezados ordenados como el índice de un libro."

Para el énfasis, dos parejas de etiquetas se ven igual pero significan cosas distintas para el navegador:

<strong>Importancia real del contenido — recomendado
<b>Solo estilo visual, sin importancia especial
<em>Énfasis real: cambia el tono de la frase — recomendado
<i>Solo estilo visual: nombres, términos técnicos
05

Enlaces básicos y errores comunes

La etiqueta <a> crea un enlace. El destino se indica dentro del atributo href.

<a href="equipo.html">Conocé al equipo</a>
// Dos tipos de destino
Interno: "equipo.html" → otra página de mi sitio
Externo: "https://..." → otro sitio en internet
TECHI DICE
"El texto que va entre <a> y </a> es lo único que el visitante ve y puede tocar. El href es el mapa; el texto es el cartel que invita a caminar."

Antes de seguir, cuatro errores que aparecen apenas se empieza a escribir HTML:

✗ <p>Texto sin cerrar ✓ <p>Texto</p> Olvidar la etiqueta de cierre
✗ <P>Texto</p> ✓ <p>Texto</p> Mezclar mayúsculas y minúsculas
✗ <a>Enlace</a> ✓ <a href="...">Enlace</a> Enlace sin destino (href)
✗ <h1><h2>Título</h2></h1> ✓ <h1>Título</h1> Anidar encabezados entre sí
✏️
Para practicar
Con estas etiquetas ya podés armar tu primera página:
  1. Abrí el editor local y creá un archivo .html
  2. Armá la estructura básica: html, head, body
  3. Agregá un h1 con el nombre de tu proyecto
  4. Escribí un párrafo con una palabra en negrita
  5. Sumá un enlace hacia la página del equipo
Ya sabés qué es cada cosa. Ahora falta cómo se ve.

Con la estructura resuelta, el siguiente paso es darle estilo: colores, tipografías y distribución visual con CSS.
