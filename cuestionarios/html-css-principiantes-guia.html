Estructura y estilo: HTML y CSS

Los dos lenguajes que van a construir el sitio de nuestro proyecto de promoción: HTML define qué contenido hay y en qué orden; CSS define el estilo — colores, tipografías y distribución visual.

📖 5 bloques ⏱ ~9 minutos de lectura 🎯 1er curso
// En esta guía
1. ¿Qué es HTML? 2. ¿Qué es CSS? 3. Conectar CSS con HTML 4. Selectores y propiedades 5. El modelo de caja
01

¿Qué es HTML?

HTML

HyperText Markup Language

Es el lenguaje que organiza el contenido de una página: qué es un título, qué es un párrafo, qué es una imagen, qué es un enlace. No define colores ni tamaños de letra — solo dice qué es cada cosa.

La analogía de Techi

"Piensen en el esqueleto de una casa: paredes, puertas y ventanas ya ubicadas en su lugar. Todavía no hay pintura, ni muebles, ni decoración — pero ya se distingue el living del dormitorio. Eso es HTML: la estructura, antes del estilo."

// Para recordar
HTML responde "qué es cada cosa", no "cómo se ve".
02

¿Qué es CSS?

CSS

Cascading Style Sheets

Es el lenguaje que define cómo se ve cada elemento del HTML: colores, tipografías, tamaños, espacios y distribución en la pantalla. El mismo HTML puede tener infinitas apariencias distintas según el CSS que se le aplique.

La analogía de Techi

"Ahora pintamos la casa, elegimos los muebles y la decoración. La estructura (HTML) no cambió: las paredes siguen en el mismo lugar. Pero con otra pintura y otros muebles, la misma casa se ve completamente distinta. Eso es CSS."

// Para recordar
CSS responde "cómo se ve", no "qué es".
03

Cómo se conecta CSS con HTML

Hay tres caminos posibles para aplicar estilo. En el proyecto de promoción se usa el método externo: un style.css por sitio.

En línea

Directo en la etiqueta, con el atributo style. Rápido, pero desordenado para un sitio completo.

<p style="color: orange;">
Interno

Dentro de una etiqueta <style> en el <head>. Sirve solo para esa página.

<style>
  p { color: orange; }
</style>
Externo — recomendado

Un archivo aparte (style.css) enlazado desde el head. Un solo archivo controla el estilo de todo el sitio.

<link rel="stylesheet"
  href="style.css">
04

Selectores y propiedades más usadas

Un selector es a quién le habla el estilo. Tres formas básicas de elegir:

p { }
Etiqueta
Aplica a todos los elementos de ese tipo en la página.
.destacado { }
Clase
Aplica a cualquier elemento con class="destacado". Se reutiliza.
#titulo-principal { }
ID
Aplica a un único elemento con id="titulo-principal". No se repite.

Y las propiedades más usadas para darle estilo a lo que seleccionaste:

colorColor del texto
background-colorColor de fondo
font-familyTipo de letra
font-sizeTamaño del texto
marginEspacio afuera del elemento
paddingEspacio adentro del elemento, antes del borde
// Sintaxis
selector { propiedad: valor; }
05

El modelo de caja

Todo elemento HTML ocupa espacio siguiendo este mismo orden: contenido → padding → border → margin.

margin
border
padding
contenido
Contenido

El texto o la imagen en sí

Padding

Espacio interno, entre el contenido y el borde

Border

El borde del elemento

Margin

Espacio externo, entre el elemento y sus vecinos

Uniendo las dos piezas, así se ve un ejemplo real del proyecto de promoción:

index.html

<h1 class="titulo">
  Reciclaje Kiosco
</h1>
<p class="lema">
  Menos residuos, más chipá
</p>

style.css
.titulo {
  color: #FF8C42;
}
.lema {
  font-size: 18px;
}
