Pautas para un buen proyecto ICIENTEC

❓
Una pregunta concreta

No un tema general — una pregunta que puedas responder con datos reales recolectados por ti.

📊
Datos propios

Encuestas al curso, mediciones del entorno, registros propios. No datos bajados de internet.

💡
Solución ejecutable

Una app, un sistema, un prototipo funcional. Algo que alguien pueda usar, no solo leer.

🤝
Puede ser intercurso

Los equipos pueden formarse entre distintos cursos o modalidades. La investigación no tiene fronteras de aula.

📅
Destino: septiembre

La feria ICIENTEC es en septiembre. No es una sorpresa — es el resultado de meses de trabajo constante.

🔗
Conecta con las materias

El proyecto más fuerte es el que cruza fronteras entre materias: datos de Laboratorio, lógica de Algorítmica.

// Hilo conductor de los 3 años

Proyecto de Promoción

Un sistema real que construyes progresivamente durante todo el bachillerato. Cada año agrega una capa. Al graduarte, tienes algo que funciona. No es paralelo a las materias — es la aplicación de todas ellas.

TECHI

"El proyecto de promoción no es algo que haces al final. Es algo que construyes desde el primer año. Cuando llegas a 3ro, ya tienes la mitad del camino recorrido."

1ro
Definir el problema y validar la necesidad
Etapa de investigación y viabilidad

Identificas un problema real, lo investigas con datos propios, encuestas a los afectados y analizas viabilidad técnica, legal y económica. Las herramientas de Laboratorio 1 — Excel, Word, PowerPoint — son las herramientas profesionales reales de esta etapa.

Excel · análisis de datos Word · informe técnico PowerPoint · presentación Encuesta · recolección Viabilidad técnica Viabilidad económica
📄 Entregable: informe + PPT + datos tabulados
// consigna aplicada · 1er curso
Armá el informe de fundamentación con las herramientas de esta etapa: datos recolectados con un formulario, organizados en Excel, presentados en un documento de Word con estructura profesional, y defendidos en una presentación breve.
📘 Formularios 📘 Word 📘 Presentaciones
🤖 IA en esta etapa: sirve para redactar un borrador del informe o generar ideas de preguntas para el formulario — no para inventar datos de la encuesta ni para sacar conclusiones sin haber mirado los datos reales.
2do
Modelar y programar la solución
Etapa de diseño y prototipo

Con los requerimientos definidos, empiezas a construir. Modelas la solución con diagramas y DER, programas módulos básicos con Python, implementas estructuras de datos y persistencia. Al final de 2do, el prototipo ya funciona.

Algorítmica 2 · pseudocódigo Python · prototipo Arreglos · estructuras Lab 2 · paradigmas DER · primer modelo Requerimientos cerrados
💻 Entregable: prototipo funcional + requerimientos
// consigna aplicada · 2do curso
Antes de programar, validá el diseño con el público objetivo: un formulario corto para detectar qué esperan del prototipo o qué les resulta confuso de una primera versión, antes de invertir tiempo construyéndola mal.
📘 Formularios
🤖 IA en esta etapa: sirve para generar ideas de diseño de interfaz o para entender un error de código — no para que te escriba el programa completo. El prototipo tiene que poder explicarse línea por línea.
3ro
Implementar, optimizar y defender
Etapa de implementación y defensa formal

Implementas el sistema completo. Base de datos relacional normalizada, POO con Java, integración de todos los módulos. Documentación técnica completa, pruebas finales y defensa formal ante un jurado evaluador.

Java + POO Base de datos relacional Normalización 3FN SQL completo Documentación técnica Defensa formal
🎓 Entregable: sistema implementado + defensa formal
// consigna aplicada · 3er curso
Cerrá el ciclo evaluando el producto terminado: un formulario de feedback con usuarios reales del sistema, documentación técnica en Word y la defensa final armada como presentación — el mismo circuito de 1er curso, ahora sobre el sistema real.
📘 Formularios 📘 Word 📘 Presentaciones
🤖 IA en esta etapa: sirve para redactar un primer borrador de la documentación técnica o revisar errores en el código — no para escribir el guion de la defensa oral. Las decisiones de diseño tenés que poder explicarlas vos, sin depender de un texto generado.
// pautas generales del proyecto de promoción
👥
Todo el curso participa

Es obligatorio para todos. Pueden trabajar con los mismos compañeros del ICIENTEC o con otros distintos.

🔄
Continúa cada año

No empieza de cero en 2do ni en 3ro. Lo que construiste el año anterior es la base del siguiente.

🌐
Problema real

El sistema debe resolver un problema real e identificable. No ejercicios de práctica — algo que alguien necesite.

📚
Aplica todo lo aprendido

Cada asignatura aporta algo. No es un proyecto de Laboratorio — es el proyecto donde todo converge.

📋
Documentación desde 1ro

Se documenta desde el primer año. La defensa de 3ro se basa en todo el proceso, no solo en el resultado.

🎤
Defensa ante jurado

La presentación final en 3ro es una defensa formal. El técnico explica, justifica y demuestra lo que construyó.
